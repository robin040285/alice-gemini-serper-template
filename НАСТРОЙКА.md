# Фоновые ответы для «Умного собеседника»

## Что изменилось

Быстрый ответ можно получить сразу. Если он не готов в короткое окно, навык
отвечает: «Готовлю ответ. Через несколько секунд скажите “продолжить”».
Сам запрос к Gemini продолжает работать после этой фразы.

Скажите «продолжить», чтобы получить результат. Если задача ещё выполняется,
навык сообщает об этом. Повторять сам вопрос не требуется.

Другой вопрос во время подготовки не заменяет предыдущий: навык просит сначала
получить ответ или сказать «отмена». Команды «отмена» и «начать сначала» отменяют
текущую задачу и очищают историю. Уже отправленный запрос Google может закончиться,
но его результат больше не будет выдан.

Gemini получает до 20 секунд на попытку. При 500/502/503/504, сетевой ошибке или
таймауте выполняется ещё одна попытка с небольшой паузой. При 429 и неверном ключе
повтор не выполняется. После двух неудач навык честно сообщает об ошибке.

## Перед загрузкой файлов: бесплатная база

1. Откройте https://console.upstash.com/ и войдите через GitHub.
2. Создайте базу Redis с названием `alice-answers`.
3. Выберите тариф **Free**, без банковской карты, платного тарифа и Auto Upgrade.
   Можно выбрать доступный европейский регион, близкий к региону вашей функции Vercel.
4. В карточке базы найдите раздел REST API: URL и обычный токен с правом записи
   (не Read Only Token). Не отправляйте токен в чат и не загружайте его в GitHub.
5. В проекте Vercel → Environment Variables добавьте для **Production**:
   - `UPSTASH_REDIS_REST_URL` — HTTPS-адрес REST API базы; тип Config.
   - `UPSTASH_REDIS_REST_TOKEN` — REST-токен; тип Secret.
6. Существующие `GEMINI_API_KEY`, `SERPER_API_KEY` и `GEMINI_MODEL` оставьте.

Тарифы проверены 27 октября 2026: Upstash Free — 250 MB и 500 000 команд в месяц.
Это лимиты, а не безлимитное обслуживание. Карта не нужна для Free.
Условия: https://upstash.com/pricing/redis

## Загрузка обновления

1. Распакуйте ZIP. Внутри должны быть папки `api`, `lib`, `tests`,
   а также `package.json`, `vercel.json` и этот файл.
2. Откройте корень вашей копии GitHub — страницу, где находится README.
3. Выберите Add file → Upload files и перетащите **содержимое** распакованной папки.
   Важно сохранить папки: обработчик должен попасть в `api/index.js`,
   остальные рабочие файлы — в `lib/`.
4. Нажмите Commit changes.
5. Дождитесь **Ready** у последнего Production-развёртывания Vercel.

`vercel.json` задаёт максимум 60 секунд для функции; это время для фоновой работы,
а не время ожидания Алисы. Обновление `package.json` добавляет официальный пакет
`@vercel/functions`. Vercel устанавливает его автоматически. В конфигурации
проекта не нужно задавать отдельную команду сборки.

## Подтверждение работы

1. Откройте ваш прежний адрес `/api`. Он должен показывать
   `mode: "background-v2"` и `storage_configured: true`.
   Это подтверждает наличие настроек, но не проверяет доступ к самой базе.
2. В Яндекс Диалогах → опубликованная версия → Тестирование начните новый разговор.
3. Задайте вопрос. Если навык попросит, через 5–10 секунд скажите «продолжить».
4. Уточните ответ следующим вопросом: контекст последних восьми сообщений сохраняется.
5. Скажите «начать сначала», чтобы очистить историю.

Адрес вебхука и публикацию навыка менять не требуется. Если появляются ошибки
подключения хранилища, проверьте REST URL, токен с правом записи и Production.
Если переменные добавлялись после загрузки файлов, выполните Redeploy.

## Ограничения и хранение

- Вопрос, краткая история, готовый ответ и служебные записи хранятся в вашей
  базе Upstash. Запись автоматически удаляется после 24 часов без изменений.
  Идентификатор пользователя сохраняется в виде хеша; вопросы и ответы — обычным текстом.
- Авторизованный пользователь может продолжить с другого устройства под тем же
  аккаунтом. Для анонимного пользователя состояние связано с экземпляром приложения.
- Это ограниченная фоновая работа Vercel через `waitUntil`, а не отдельная
  гарантированная очередь. При остановке функции, сбое платформы или невозможности
  записать результат задача может прерваться. Через 75 секунд навык распознает
  незавершённую задачу и попросит повторить вопрос.
- Алиса сама не начинает говорить после завершения задачи: нужна команда «продолжить».
- Бесплатные лимиты Gemini, Vercel и Upstash продолжают действовать. Оплата и
  платные тарифы этим кодом не включаются. Недоступность Google код не устраняет.
- Новые вопросы ограничены 2000 символами, ответ — 1024 символами.
- Поиск получает до 3,5 секунды. При его сбое модель получает указание не выдавать
  сведения за проверенные и актуальные. Точного маршрутизатора с пробками здесь нет.
- Никакие ключи и тексты вопросов не записываются приложением в логи.

## Проверки разработчика

Команда `node --test` проверяет медленный ответ после возврата из обработчика,
повторную доставку запросов, контекст, разные сессии и пользователей, отмену,
зависшую задачу, временные ошибки Gemini, квоты и конфликты сохранения.
Проверки используют имитации Gemini и Redis. Живую работу Vercel, Google и вашей
базы требуется подтвердить после развёртывания; до этого она не проверена.

Документация Vercel: https://vercel.com/docs/functions/functions-api-reference/vercel-functions-package#waituntil

## Откат

Верните файлы из отдельного архива `alice-rollback.zip`: старые `api/index.js`,
`package.json` и `vercel.json`. Остальные новые файлы не вызываются старым обработчиком.
Дождитесь Ready. Старый режим снова будет ограничивать ожидание Gemini тремя секундами.
